VERDICT
This is a real improvement, not just documentation edits. The cached-append
workspace fix works on CPU; causality and partition agreement are preserved.
Unsupported hybrid cache and bidirectional modes now reject requests clearly.
DIMACS clause streaming and clause preservation are repaired for the tested valid
inputs. The old FP16 state=300 normalization failure is fixed. Production algebra
and Poisson residual tests have been strengthened, and CPU wheel installation works.

Not a clean production sweep yet. Hybrid outputs still change with chunk_size;
low-precision state arithmetic still has reproduced failures; normalization still
fails at a larger synthetic position despite fixing the old 70,000-position case; malformed DIMACS remains
unchecked. GPU correctness, autocast, and end-to-end model quality remain open.
Benchmark methodology is better, but the tables still lack reproducible raw logs
and the remaining projection/quality claims exceed what the code demonstrates.

1. Separate hybrid recurrence semantics from computational chunk_size.
   Location: tensorsat/hybrid.py:168-192; tensorsat/stabilizer.py:60-75.
   Evidence: REPRODUCED CPU, unchanged from round 2. Seed 1701 following the

   Prior state is RMS-normalized at block boundaries, but current-block state is
